# Raccourcis clavier

Le projet met en place une logique de clavier simple pour accélérer la création de motifs.

## Pads

Les pads sont accessibles avec la disposition suivante :

- ligne 1 : `1 2 3`
- ligne 2 : `q w e`
- ligne 3 : `a s d`
- ligne 4 : `z x c`

## Contrôles

- `Espace` : play / stop
- `r` : rec on/off
- `Escape` : fermer l’aide

## Séquenceur

- `ptn` : sélection du pattern et entrée numérique
- `tempo` : réglage du BPM
- `length` : longueur du pattern
- `bar` : déplacement dans la grille
- `timing` : subdivision du temps
- `fx` : réglage des effets
- `sound` : édition sonore du pad courant
- `sample` : enregistrement / suppression d’un échantillon

## Utilisation de la touche shift

Le mode `shift` active des fonctions spéciales, par exemple :

- `shift + sound` : édition avancée de hauteur / durée
- `shift + ptn` : effacer le pattern
- `shift + sample` : supprimer le sample du pad sélectionné

## Astuce pratique

Le clavier est conçu pour une utilisation rapide en performance, mais la souris reste la meilleure option pour les réglages précis dans les modes `fx`, `sound` et `sample`.
